Files:

- stars.html       Stars and stellar evolution
- missions.html    Space missions
- news.html        Research and discovery updates
- future.html      Future exploration
- assistant.html  Offline astronomy FAQ assistant and help
- account.html     Front-end account form demonstration
- style.css        Shared responsive visual theme
- app.js           Shared search, navigation, and assistant behavior

HOW TO USE
1. Keep all 10 files in the same folder.
2. Open index.html to view the site locally.
3. To publish with GitHub Pages, upload all files directly into the root of your repository.
4. In GitHub, open Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.

NOTES
- The login/account page is a front-end demo only. It does not create accounts or authenticate users.
- The assistant is an offline FAQ-style script, not a live AI model.
- Internet access is required for the remote background images and Google Fonts.
- Mission dates and research summaries may change. Verify time-sensitive information with the linked official sources.
