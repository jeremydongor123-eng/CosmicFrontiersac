Security notice

This static HTML website cannot securely create or authenticate real accounts. It does not store passwords, but it also does not verify identities. Do not enter a real password here.

For production, use HTTPS and a trusted authentication provider or a secure backend. Store password hashes using a modern password-hashing algorithm such as Argon2id or bcrypt, use secure HttpOnly/SameSite cookies, rate-limit login attempts, add email verification and password reset flows, and never store plaintext passwords in browser storage.
